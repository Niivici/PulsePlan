# PulsePlan 首版后端与联调规格

状态：HarmonyOS 模拟器已通过注册、登录、日程创建与读回、提醒保存、周视图拖拽和拉伸、冲突时保留原时段，以及真实 DeepSeek 排程的预览、确认和持久化验证。

## 交付目标

在现有仓库下新增 `server/` Java 服务，保留 HarmonyOS 工程入口。客户端接入真实服务，覆盖登录、日程、提醒配置、AI 编排、成就和个人中心。交付包括数据库迁移、接口契约、测试、本地启动说明和客户端联调记录。

技术方案采用 Java 17、Spring Boot、Maven、Spring Security Crypto、PostgreSQL 和 Flyway。API 以 `/api/v1` 为前缀，使用 JSON。

## 分阶段验收

| 阶段 | 产品能力 | 验收行为 |
| --- | --- | --- |
| 1 | 账号与个人中心 | 普通用户可自助注册、登录和查询自己的资料。服务端由配置初始化唯一管理员，重启时保持账号不重复。注册请求无法指定管理员角色，普通用户之间的数据彼此隔离。 |
| 2 | 今日概览、日历与提醒 | 客户端按日期范围读取自己的日程。支持事件块和日程的增删改查、拖动、拉伸、完成和提醒配置。重启后数据仍可读取，删除日程后关联提醒一并清理。 |
| 3 | AI 编排 | 用户输入目标，服务端调用真实模型并返回可预览的日程建议。仅在用户确认后写入日程，整批写入具备原子性。超时和无效模型输出有明确错误，已有日程可继续操作。 |
| 4 | 成就、设置和端到端联调 | 完成日程后更新个人统计，设置可保存并重新读取。HarmonyOS 模拟器或真机连到 Java 服务，验证注册、登录、日程编辑、真实 AI 生成及确认保存。 |

## 接口与数据规则

- 首版拟采用用户名和密码注册。管理员凭据从服务端运行环境初始化。首版管理员仅保留角色，使用与普通用户相同的个人数据权限。
- 日程沿用客户端的本地日期与分钟偏移表示。API 以 ISO 日期、IANA 时区和半开区间表达查询及冲突判断。首版拟允许相邻日程，重叠时明确返回冲突。接入服务时，紧急事项可通过 AI 生成空闲时段建议，再由用户确认。
- 今天的概览、提醒及成就统计由个人日程推导。服务端保存提醒时间和配置，客户端显示提醒，系统通知待接入。
- AI 接入 DeepSeek 官方接口，默认模型为 `deepseek-v4-pro`，允许通过服务端配置切换模型。自动化测试用模拟模型响应，最终联调调用真实模型。模型密钥由服务端环境配置。
- HarmonyOS 通过可配置的 API 地址联调。验收记录应标明所用设备、实际完成的流程和验证结果。


## API 草案

以下路径均以 `/api/v1` 为前缀。注册和登录公开，其余业务接口使用 Bearer 会话令牌。会话有有效期，客户端用系统安全存储恢复登录，退出后清除本地记录并注销服务端会话。请求体中的资源 ID 不能改变资源所有者。

| 方法与路径 | 行为 |
| --- | --- |
| `POST /auth/register` | 以用户名和密码注册普通用户，返回用户资料。重复用户名返回 `409`。 |
| `POST /auth/login` | 认证后签发会话令牌。错误凭据返回 `401`。 |
| `POST /auth/logout` | 注销当前会话。 |
| `GET /me`、`PATCH /me` | 读取资料，更新显示名称和个人时区。 |
| `GET /overview?date=YYYY-MM-DD` | 返回当天的日程、待办和提醒。 |
| `GET /event-blocks`、`POST /event-blocks` | 列出或创建事件块。 |
| `GET /event-blocks/{id}`、`PATCH /event-blocks/{id}`、`DELETE /event-blocks/{id}` | 查询、编辑和删除指定事件块。有日程引用时返回 `409`。 |
| `GET /schedules?from=YYYY-MM-DD&to=YYYY-MM-DD`、`POST /schedules` | 按左闭右开的日期区间查询，或创建日程。创建时可省略事件块 ID，服务端会同时创建同名事件块。 |
| `GET /schedules/{id}`、`PATCH /schedules/{id}`、`DELETE /schedules/{id}` | 查询、编辑或删除日程。编辑涵盖时间、时长与完成状态。 |
| `GET /schedules/{id}/reminders`、`PUT /schedules/{id}/reminders` | 读取或整批替换提醒配置。 |
| `POST /ai/plans`、`POST /ai/plans/{id}/confirm` | 生成可预览草案，或重新校验并保存该草案。账号或全站每日额度耗尽时，生成接口返回 `429`。重复确认返回原保存结果。 |
| `GET /achievements` | 返回基于真实完成记录计算的个人统计与成就。 |

读取或修改其他用户的资源时返回 `404`。日程的 `startMinute`、`endMinute` 需满足 `0 <= startMinute < endMinute <= 1440`。创建、拖动、拉伸和 AI 确认共用冲突规则。同一天的相邻日程可保存，重叠返回 `409`。AI 预览不写入正式日程，确认时按数据库最新状态重新校验。
